ABOUT THE PROJECT

Built to turn an idea into a real product.

Elevating is an independent full-stack portfolio project built to explore what a thoughtful multi-user goal-planning application can look like — from the database and authentication model all the way to the interface you're using now.

The product is intentionally practical: create goals, break them into actions, track progress, and keep each user's data securely separated.

Built & deployed

Built across the stack.

The project is designed as a production-style full-stack application rather than a static frontend demo.

Frontend

  • Angular 21
  • TypeScript
  • signals
  • RxJS
  • Tailwind CSS

Backend

  • ASP.NET Core 10
  • C#
  • EF Core
  • ASP.NET Core Identity

Security

  • JWT access tokens
  • Rotating refresh sessions
  • HttpOnly refresh cookies
  • Per-user server-side ownership

Cloud & delivery

  • Azure SQL Database
  • Azure Container Apps
  • Azure Static Web Apps
  • Docker
  • GitHub Actions

What it demonstrates

A portfolio project with real application boundaries.

01

Multi-user authentication

Registration, login, logout, short-lived JWT access tokens and rotating refresh sessions.

02

Ownership & authorization

Every goal and action is isolated by authenticated user ownership on the server.

03

Useful goal workflows

Goal CRUD, ordered actions, automatic progress, overdue tracking and dashboard summaries.

04

Real querying

Search, filtering, sorting and pagination are owner-scoped before results are returned.

05

Automated quality checks

Application, integration and frontend tests run through the project's CI workflow.

06

Cloud deployment

The API, frontend and SQL database are deployed across Azure services.
